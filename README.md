# Royal Signature Wear

Frontend demo for **royalsignaturewear.online**, built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or serve the repository folder using:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

See [Azure Ubuntu / Nginx deployment](docs/deployment.md).

## Notes

Cart, billing and checkout are frontend demos only. No live payments or server-side order storage are implemented. Do not collect real customer payment information using this demo.
